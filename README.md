## 💡 طريقة البحث السريع أمام المدير:
1. اضغط على مفتاح `/` في لوحة التحكم وأنت داخل هذا المستودع.
2. اكتب اسم الميزة (مثال: `print` أو `login`).
3. سيظهر لك السطر والملف الدقيق فوراً لنسخه.
